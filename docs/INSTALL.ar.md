# تثبيت فاروق بيز مانجر

هناك ثلاث طرق. اختر واحدة.

| | لمن | التكلفة | الوقت |
|---|---|---|---|
| **أ. السحابة المجانية** | الجميع. لا حاجة إلى برمجة | مجاني | حوالي 20 دقيقة |
| **ب. خادمك الخاص** | فنيو تقنية المعلومات الذين يريدون البيانات على أجهزتهم | مجاني (أجهزتك) | حوالي ساعة |
| **ج. وضع المطور** | المبرمجون الذين يريدون تعديل الكود | مجاني | حوالي 10 دقائق |

---

## كيف يعمل

يتكون فاروق بيز مانجر من جزأين:

1. **الشاشات** — موقع يعمل في المتصفح (كروم، إيدج، سفاري، فايرفوكس؛ حاسوب أو جهاز لوحي أو هاتف).
2. **الخادم وقاعدة البيانات** — [Convex](https://www.convex.dev). يحفظ بياناتك وينفّذ كل قواعد المحاسبة.
   وهو مفتوح المصدر: استخدم سحابتهم المجانية (الطريقة أ) أو شغّله بنفسك (الطريقة ب).

تسجيل الدخول مدمج (بريد إلكتروني وكلمة مرور). لا حاجة إلى أي شركة أخرى.

---

## أ. السحابة المجانية — خطوة بخطوة

تحتاج إلى ثلاثة حسابات مجانية. استخدم البريد نفسه في الثلاثة لتسهيل الأمر.

### الخطوة 1 — GitHub (حيث يوجد الكود)

1. ادخل إلى **https://github.com** واضغط **Sign up**. أنشئ حساباً مجانياً.
2. افتح الصفحة: **https://github.com/FarooqStars/farooq-bizmanager**
3. اضغط **Fork** (أعلى اليمين)، ثم **Create fork**.
   أصبحت لديك نسختك الخاصة من البرنامج.

### الخطوة 2 — Convex (قاعدة بياناتك)

1. ادخل إلى **https://www.convex.dev** واضغط **Sign up**، واختر **Continue with GitHub**.
2. اضغط **Create a project**. سمِّه مثلاً `bizmanager`.
3. افتح المشروع واختر بيئة **Production**.
4. اذهب إلى **Settings** ثم **Deploy keys** (قد تختلف الكلمات قليلاً) واضغط **Generate production deploy key**.
5. **انسخ المفتاح** واحفظه في مكان آمن. إنه مثل كلمة مرور قاعدة بياناتك — لا تشاركه ولا تضعه على GitHub.

### الخطوة 3 — Vercel (ينشر الموقع على الإنترنت)

1. ادخل إلى **https://vercel.com** وسجّل بـ **Continue with GitHub** (خطة **Hobby** المجانية تكفي).
2. اضغط **Add New… ← Project**.
3. ابحث عن **farooq-bizmanager** في القائمة واضغط **Import**.
4. افتح **Environment Variables** وأضف متغيراً واحداً:
   - الاسم: `CONVEX_DEPLOY_KEY`
   - القيمة: المفتاح الذي نسخته في الخطوة 2
5. اترك كل شيء آخر كما هو (الإعدادات الصحيحة موجودة في المشروع) واضغط **Deploy**.
6. انتظر من 2 إلى 4 دقائق. عندما تظهر **Congratulations** اضغط على صورة موقعك لفتحه.

### الخطوة 4 — أنشئ حساب المالك

> ⚠️ افعل ذلك **فوراً**. في التثبيت الجديد، أول من يفتح الموقع يصبح هو المالك.

1. سيظهر نموذج **الإعداد لأول مرة**.
2. اكتب اسم الشركة واسمك وبريدك وكلمة مرور (8 أحرف على الأقل).
3. اضغط **أنشئ الحساب وابدأ**. أنت الآن المالك وفي لوحة التحكم.

### الخطوة 5 — أول ما تفعله

1. **ملف الشركة** — اختر دولتك. تُملأ العملة والضريبة وصيغة التاريخ والسنة المالية تلقائياً.
2. **المحاسبة ← دليل الحسابات** — استخدم الحسابات الجاهزة أو أضف حساباتك.
3. **المستخدمون والأدوار ← إضافة عضو** — أعطِ كل شخص بريداً وكلمة مرور أولية. يسجّلون الدخول من الموقع نفسه.
4. أضف منتجاتك وعملاءك ومورديك. يمكن إدخال الرصيد الافتتاحي والمخزون الافتتاحي لكل منها.

هذا كل شيء. احفظ عنوان موقعك في المفضلة.

---

## اختياري: إرسال البريد الإلكتروني

كل شيء يعمل بدونه — فقط لا تُرسل الرسائل التلقائية (تذكير السداد، الإيصالات، تنبيه نقص المخزون).

1. أنشئ حساباً مجانياً في **https://resend.com** وأضف نطاقك (يشرحون الطريقة).
2. أنشئ **API key**.
3. في لوحة Convex: المشروع ← **Production ← Settings ← Environment Variables** وأضف:
   - الاسم: `RESEND_API_KEY`
   - القيمة: مفتاحك

## التحديث إلى إصدار جديد

1. افتح نسختك على GitHub.
2. إن وُجد تحديث سيظهر زر **Sync fork**. اضغطه ثم **Update branch**.
3. خلال دقائق يعيد Vercel بناء الموقع تلقائياً. بياناتك لا تُمس.

## نسيت كلمة مرور المالك

أعضاء الفريق: يعيّن المالك كلمة مرور جديدة بزر المفتاح في **المستخدمون والأدوار**.

المالك نفسه:
1. افتح لوحة Convex ← المشروع ← **Production ← Functions**.
2. ابحث عن **authActions ← resetPasswordByEmail** واضغط **Run**.
3. أدخل ما يلي ثم شغّله:
   ```
   {"email": "you@example.com", "newPassword": "a-new-password"}
   ```
4. سجّل الدخول بكلمة المرور الجديدة.

## النسخ الاحتياطي

بياناتك في Convex. استخدم خيارات النسخ الاحتياطي والتصدير في لوحة Convex
(راجع **https://docs.convex.dev** قسم «Backup & Restore») واحتفظ بنسخة بانتظام.
كما تستطيع صفحة **البيانات** في البرنامج تصدير الجداول إلى CSV.

## ب. خادمك الخاص (لفنيي تقنية المعلومات)

شغّل خادم Convex بنفسك، واعرض الموقع من أي خادم ويب.

1. جهّز خادم Convex الخاص باتباع الدليل الرسمي:
   **https://github.com/get-convex/convex-backend/tree/main/self-hosted**
   (غالباً عبر Docker). سجّل عنوان الخادم (مثلاً `http://your-server:3210`) وأنشئ **admin key** كما يشرح الدليل.
2. على جهاز فيه Node.js 20 أو أحدث و pnpm:
   ```bash
   git clone https://github.com/FarooqStars/farooq-bizmanager.git
   cd farooq-bizmanager
   pnpm install
   ```
3. أنشئ ملف `.env.local`:
   ```
   CONVEX_SELF_HOSTED_URL=http://your-server:3210
   CONVEX_SELF_HOSTED_ADMIN_KEY=<your admin key>
   VITE_CONVEX_URL=http://your-server:3210
   ```
4. ارفع كود الخادم ثم ابنِ الموقع:
   ```bash
   npx convex deploy
   pnpm build
   ```
5. اعرض مجلد `dist` بأي خادم ويب (nginx، Caddy، IIS…). يجب توجيه كل مسار غير معروف إلى `index.html`.
6. افتح الموقع وأكمل **الإعداد لأول مرة** (الخطوة 4 من الطريقة أ).

للبريد الإلكتروني، عيّن المفتاح على الخادم:
```bash
npx convex env set RESEND_API_KEY <your key>
```

جُرّبت هذه الطريقة مع خادم Convex خاص على لينكس.

## ج. وضع المطور

```bash
git clone https://github.com/FarooqStars/farooq-bizmanager.git
cd farooq-bizmanager
pnpm install
npx convex dev      # ينشئ قاعدة بيانات تطوير ويبقيها متزامنة
pnpm dev            # في نافذة ثانية — الموقع على http://localhost:5173
pnpm test           # 128 اختباراً
```

أين توجد الأشياء:

| المجلد | المحتوى |
|---|---|
| `convex/` | الخادم: بنية قاعدة البيانات وكل قواعد الأعمال والمحاسبة |
| `convex/lib/ledger.ts` | محرك الترحيل — كل قيد يمر من هنا |
| `convex/authActions.ts` | تسجيل الدخول المدمج |
| `convex/__tests__/` | الاختبارات |
| `src/pages/` | مجلد لكل شاشة |
| `src/locales/` | النصوص بالإنجليزية والأردية والعربية |

قاعدة للمساهمين: كل تغيير يحرّك المال يجب أن يرحّل قيداً متوازناً عبر `lib/ledger.ts`،
ويحترم قفل الترحيل (`enforcePostingDate`)، ويأتي مع اختبار **يفشل** عند إزالة التغيير.
