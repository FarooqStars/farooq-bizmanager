# فاروق بز مینیجر کی تنصیب

> 🟢 **پہلے آزما کر دیکھیں:** https://farooq-bizmanager-demo.vercel.app — اور **Try the demo** دبائیں۔

تین طریقے ہیں۔ ایک چن لیں۔

| | کس کے لیے | خرچ | وقت |
|---|---|---|---|
| **الف۔ مفت کلاؤڈ** (یہی صفحہ) | ہر کوئی۔ پروگرامنگ کی ضرورت نہیں | مفت | تقریباً 20 منٹ |
| **ب۔ اپنا سرور** ([الگ رہنمائی](SELF-HOSTING.ur.md)) | آئی ٹی والے، جو ڈیٹا اپنی مشین پر رکھنا چاہیں | اپنا سرور | 1 سے 2 گھنٹے |
| **ج۔ ڈویلپر طریقہ** (اس صفحے کے آخر میں) | پروگرامر جو کوڈ بدلنا چاہیں | مفت | تقریباً 10 منٹ |

---

## یہ کیسے چلتا ہے

فاروق بز مینیجر کے دو حصے ہیں:

1. **اسکرینیں** — ایک ویب سائٹ جو براؤزر میں چلتی ہے (کمپیوٹر، ٹیبلٹ یا موبائل)۔ اسے **Vercel** مفت میں انٹرنیٹ پر لاتا ہے۔
2. **سرور اور ڈیٹا بیس** — **[Convex](https://www.convex.dev)**۔ یہ آپ کا ڈیٹا رکھتا ہے اور حساب کتاب کے سارے اصول چلاتا ہے۔ یہ اوپن سورس ہے؛ یہاں اس کا مفت کلاؤڈ استعمال ہوتا ہے۔

سائن اِن اندر ہی بنا ہوا ہے (ای میل اور پاس ورڈ)۔ کسی دوسری کمپنی کی ضرورت نہیں۔

**شروع کرنے سے پہلے:** Convex یا Vercel میں کبھی کارڈ کی معلومات نہ ڈالیں۔ مفت پلان پر کبھی کوئی پیسہ نہیں کٹ سکتا۔

---

## الف۔ مفت کلاؤڈ — قدم بہ قدم، تصویروں کے ساتھ

تین مفت اکاؤنٹ چاہییں: GitHub، Convex اور Vercel۔
Convex اور Vercel میں **اپنے GitHub اکاؤنٹ سے** داخل ہوں — سب آسان رہتا ہے۔

تصویروں میں سرخ خانے بتاتے ہیں کہ کہاں دبانا ہے۔

### قدم 1 — GitHub: اپنی نقل

1. **https://github.com** پر مفت اکاؤنٹ بنائیں۔
2. یہ صفحہ کھولیں: **https://github.com/FarooqStars/farooq-bizmanager**
3. **Fork** دبائیں، پھر **Create fork**۔ اب آپ کی اپنی نقل بن گئی۔

### قدم 2 — Convex: آپ کا ڈیٹا بیس

1. **https://www.convex.dev** پر جائیں، سائن اپ کریں، **Continue with GitHub** چنیں اور اجازت دیں (یہ صرف آپ کا نام اور ای میل پڑھتا ہے)۔
2. ایک پروجیکٹ بنائیں، مثلاً `bizmanager`۔
3. Convex پہلے **Development** بنانے کا کہتا ہے۔ اوپر سبز بٹن کھول کر اس کی جگہ **Production** چنیں۔ اپنے قریب کا علاقہ چنیں (خلیج اور پاکستان کے لیے یورپ قریب ہے؛ امریکہ کے لیے US East) اور **Create deployment** دبائیں۔

![پروڈکشن](images/install/01-convex-production.png)

4. **Settings ← General** میں جائیں اور **Deploy Keys** ڈھونڈیں۔ **پروڈکشن کی چابی** بنانے والا بٹن دبائیں۔
5. یوں بھریں:
   - **نام:** `vercel`
   - **مدت:** جیسی ہے ویسی رہنے دیں
   - **اجازتیں:** صرف ایک پر نشان: `deployment:deploy` (اوپر بائیں)۔ «سب چنیں» **نہ** دبائیں۔
   - **Create** دبائیں۔

![صرف ایک اجازت والی چابی](images/install/03-convex-deploy-key.png)

6. **چابی کاپی کر کے** اگلے قدم کے لیے نوٹ پیڈ میں رکھیں۔ یہ آپ کے ڈیٹا بیس کا پاس ورڈ ہے: کسی کو نہ دیں، اس کی تصویر نہ بھیجیں، گٹ ہب پر کبھی نہ ڈالیں۔

### قدم 3 — Vercel: ویب سائٹ انٹرنیٹ پر

1. **https://vercel.com/signup** پر جائیں۔ **ذاتی منصوبے (Hobby)** چنیں، نام لکھیں اور **Continue with GitHub**۔

![مفت پلان](images/install/04-vercel-hobby.png)

2. **Add New… ← Project** دبائیں۔ Vercel گٹ ہب پر اجازت مانگے گا۔ **Only select repositories** چنیں اور صرف اپنا `farooq-bizmanager` دیں۔ **Install** دبائیں۔

![صرف ایک ریپو کی اجازت](images/install/05-github-app.png)

3. `farooq-bizmanager` کے سامنے **Import** دبائیں۔
4. ترتیبات کے صفحے پر:
   - **Project Name:** یہی آپ کی ویب سائٹ کا پتہ بنے گا، مثلاً `mycompany-books` ← `mycompany-books.vercel.app`۔
   - **Environment Variables** کھول کر ڈالیں: **Key** میں `CONVEX_DEPLOY_KEY` اور **Value** میں قدم 2 والی چابی۔
   - **Environments:** اسے صرف **Production** کر دیں۔ (آپ کی نقل عوامی ہے؛ اس سے دوسروں کی تجاویز والے آزمائشی ورژن کبھی آپ کی چابی استعمال نہیں کر سکیں گے۔)
   - باقی کچھ نہ بدلیں — درست ترتیب پروجیکٹ میں پہلے سے موجود ہے۔
   - **Create Project** دبائیں۔

![نام، چابی، صرف پروڈکشن](images/install/06-vercel-env.png)

5. **Deploy** دبائیں۔ نیچے *Optional Integrations* میں *Convex* کے سامنے **Add** **نہ** دبائیں — وہ ایک دوسرا، خالی ڈیٹا بیس بنا دے گا۔ آپ کا ڈیٹا بیس پہلے سے تیار ہے۔

![Deploy — Add نہیں](images/install/07-vercel-deploy.png)

6. Vercel دو مرحلوں والی تصدیق کی تجویز دے سکتا ہے۔ اگر فون میں تصدیق والی ایپ ہے تو لگا لیں؛ ورنہ چھوڑ دیں اور بعد میں لگائیں۔
7. 2 سے 4 منٹ انتظار کریں، جب تک **Congratulations!** نہ آئے۔

![کامیابی](images/install/08-vercel-success.png)

8. **Continue to Dashboard** دبائیں۔ آپ کا پتہ **Domains** کے نیچے لکھا ہے۔ **Visit** دبائیں۔

![آپ کی ویب سائٹ کا پتہ](images/install/11-vercel-domains.png)

### قدم 4 — مالک کا اکاؤنٹ بنائیں

> ⚠️ یہ **فوراً** کریں۔ نئی تنصیب پر جو شخص سب سے پہلے ویب سائٹ کھولے، وہی مالک بنتا ہے۔

1. ویب سائٹ پر **پہلی بار کی ترتیب** آئے گی۔
2. کمپنی کا نام، اپنا نام، ای میل اور پاس ورڈ (کم از کم 8 حروف) لکھیں۔
3. **اکاؤنٹ بنائیں اور شروع کریں** دبائیں۔ اب آپ مالک ہیں۔

![پہلی بار کی ترتیب](screenshots/00b-first-time-setup-urdu.png)

### قدم 5 — پہلے کرنے کے کام

1. **کمپنی پروفائل** — اپنا ملک چنیں۔ کرنسی، ٹیکس، تاریخ کا انداز اور مالی سال خود بھر جاتے ہیں۔
2. **حساب کتاب ← کھاتوں کی فہرست** — تیار کھاتے استعمال کریں یا اپنے بنائیں۔
3. **صارفین اور کردار ← ٹیم ممبر شامل کریں** — ہر شخص کو ای میل اور ابتدائی پاس ورڈ دیں۔
4. مصنوعات، گاہک اور سپلائر ڈالیں۔ ہر ایک پر ابتدائی بقایا اور ابتدائی اسٹاک لکھا جا سکتا ہے۔

اپنی ویب سائٹ کا پتہ محفوظ کر لیں۔ بس۔

---

## اختیاری: ای میل بھیجنا

اس کے بغیر سب کچھ چلتا ہے؛ صرف خودکار ای میلیں (یاددہانی، رسید، کم اسٹاک کا انتباہ) نہیں جاتیں۔

1. **https://resend.com** پر مفت اکاؤنٹ بنائیں، اپنا ڈومین جوڑیں اور ایک **API key** بنائیں۔
2. Convex میں: پروجیکٹ ← **Production ← Settings ← Environment Variables** ← **Add**: نام `RESEND_API_KEY`، قیمت آپ کی چابی۔

![متغیرات کی جگہ](images/install/02-convex-env-vars.png)

## نئے ورژن پر اپڈیٹ

1. گٹ ہب پر اپنی نقل کھولیں۔ نیا ورژن ہو تو **Sync fork** ← **Update branch** نظر آئے گا۔
2. Vercel خود ویب سائٹ دوبارہ بنا دیتا ہے۔ آپ کا ڈیٹا نہیں چھیڑا جاتا۔

## مالک کا پاس ورڈ بھول گئے

ٹیم کے ارکان: مالک **صارفین اور کردار** میں چابی کے بٹن سے نیا پاس ورڈ لگا دے۔

مالک خود: Convex ← پروجیکٹ ← **Production ← Functions** ← **authActions ← resetPasswordByEmail**۔ **Unlock Edits** دبائیں (پروڈکشن یہ مانگتا ہے)، یہ لکھیں:

```
{"email": "you@example.com", "newPassword": "a-new-password"}
```

اور **Run action** دبائیں۔

## بیک اپ

آپ کا ڈیٹا Convex میں ہے۔ Convex ڈیش بورڈ میں **Settings ← Backup & Restore** باقاعدگی سے استعمال کریں اور نقل کسی دوسری جگہ بھی رکھیں۔ ایپ کا **ڈیٹا** والا صفحہ بھی جدولیں CSV میں نکال سکتا ہے۔

## عوامی نمونہ چلانا (سرکاری نمونے کی طرح)

اوپر والے طریقے سے ہی تنصیب کریں، پھر:

1. Convex میں متغیر ڈالیں: `DEMO_MODE` = `true` (تصویر «ای میل بھیجنا» والے حصے میں)۔
2. Convex ← **Production ← Functions ← demoActions ← reset**۔ **Unlock Edits** دبائیں، پھر `{}` کے ساتھ **Run action**۔

![Unlock Edits](images/install/09-convex-unlock.png)

![نمونہ بن گیا](images/install/10-convex-reset-done.png)

3. اپنی ویب سائٹ کھولیں۔ اب اس پر **نمونہ آزمائیں** نظر آئے گا:

![نمونہ آزمائیں](images/install/12-demo-sign-in.png)

نمونے میں پاس ورڈ، کردار اور لوگوں کو ہٹانا بند رہتا ہے، ہر اسکرین پر «عوامی نمونہ» کی پٹی آتی ہے، اور ہر رات 00:00 UTC پر سب کچھ مٹ کر دوبارہ بنتا ہے۔
جب تک پہلی صفائی نہ چلے، سائٹ پہلی بار کی ترتیب کی جگہ «نمونہ تیار ہو رہا ہے» دکھاتی ہے، تاکہ کوئی آنے والا خود مالک نہ بن سکے۔

**اصلی ڈیٹا والی تنصیب پر `DEMO_MODE` کبھی نہ لگائیں** — رات کی صفائی سب کچھ مٹا دیتی ہے۔

## ج۔ ڈویلپر طریقہ

```bash
git clone https://github.com/FarooqStars/farooq-bizmanager.git
cd farooq-bizmanager
pnpm install
npx convex dev      # ترقیاتی ڈیٹا بیس بناتا ہے اور ساتھ رکھتا ہے
pnpm dev            # دوسری ونڈو میں — http://localhost:5173
pnpm test           # 131 ٹیسٹ
```

| فولڈر | اندر کیا ہے |
|---|---|
| `convex/` | سرور: ڈیٹا بیس کی ساخت، کاروبار اور حساب کتاب کے سارے اصول |
| `convex/lib/ledger.ts` | اندراج کا انجن — ہر روزنامچہ اندراج یہیں سے گزرتا ہے |
| `convex/authActions.ts` | اندرونی سائن اِن |
| `convex/demoActions.ts` | عوامی نمونے کی صفائی |
| `convex/__tests__/` | ٹیسٹ |
| `src/pages/` | ہر اسکرین کا الگ فولڈر |
| `src/locales/` | انگریزی، اردو اور عربی عبارتیں |

حصہ ڈالنے والوں کے لیے اصول: پیسہ ہلانے والی ہر تبدیلی `lib/ledger.ts` سے متوازن اندراج کرے، اندراج کے تالے (`enforcePostingDate`) کا احترام کرے، اور اس کے ساتھ ایسا ٹیسٹ ہو جو تبدیلی ہٹانے پر **فیل** ہو۔
