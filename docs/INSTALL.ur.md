# فاروق بز مینیجر کی تنصیب

تین طریقے ہیں۔ ایک چن لیں۔

| | کس کے لیے | خرچ | وقت |
|---|---|---|---|
| **الف۔ مفت کلاؤڈ** | ہر کوئی۔ پروگرامنگ کی ضرورت نہیں | مفت | تقریباً 20 منٹ |
| **ب۔ اپنا سرور** | آئی ٹی والے، جو ڈیٹا اپنی مشین پر رکھنا چاہیں | مفت (اپنا ہارڈویئر) | تقریباً 1 گھنٹہ |
| **ج۔ ڈویلپر طریقہ** | پروگرامر جو کوڈ بدلنا چاہیں | مفت | تقریباً 10 منٹ |

---

## یہ کیسے چلتا ہے

فاروق بز مینیجر کے دو حصے ہیں:

1. **اسکرینیں** — ایک ویب سائٹ جو براؤزر میں چلتی ہے (کروم، ایج، سفاری، فائر فاکس؛ کمپیوٹر، ٹیبلٹ یا موبائل)۔
2. **سرور اور ڈیٹا بیس** — [Convex](https://www.convex.dev)۔ یہ آپ کا ڈیٹا رکھتا ہے اور حساب کتاب کے سارے اصول چلاتا ہے۔
   یہ اوپن سورس ہے: ان کا مفت کلاؤڈ استعمال کریں (طریقہ الف) یا خود چلائیں (طریقہ ب)۔

سائن اِن اندر ہی بنا ہوا ہے (ای میل اور پاس ورڈ)۔ کسی دوسری کمپنی کی ضرورت نہیں۔

---

## الف۔ مفت کلاؤڈ — قدم بہ قدم

تین مفت اکاؤنٹ چاہییں۔ آسانی کے لیے تینوں میں ایک ہی ای میل استعمال کریں۔

### قدم 1 — GitHub (جہاں کوڈ رکھا ہے)

1. **https://github.com** پر جائیں اور **Sign up** دبائیں۔ مفت اکاؤنٹ بنائیں۔
2. یہ صفحہ کھولیں: **https://github.com/FarooqStars/farooq-bizmanager**
3. اوپر دائیں طرف **Fork** دبائیں، پھر **Create fork**۔
   اب سافٹ ویئر کی آپ کی اپنی نقل بن گئی۔

### قدم 2 — Convex (آپ کا ڈیٹا بیس)

1. **https://www.convex.dev** پر جائیں، **Sign up** دبائیں، اور **Continue with GitHub** چنیں۔
2. **Create a project** دبائیں۔ نام رکھیں، مثلاً `bizmanager`۔
3. پروجیکٹ کھولیں اور **Production** والا حصہ چنیں۔
4. **Settings** میں **Deploy keys** پر جائیں (الفاظ تھوڑے مختلف ہو سکتے ہیں) اور **Generate production deploy key** دبائیں۔
5. **چابی کاپی کر کے** محفوظ جگہ رکھ لیں۔ یہ آپ کے ڈیٹا بیس کے پاس ورڈ جیسی ہے — کبھی کسی کو نہ دیں، نہ گٹ ہب پر ڈالیں۔

### قدم 3 — Vercel (ویب سائٹ کو انٹرنیٹ پر لاتا ہے)

1. **https://vercel.com** پر جائیں اور **Continue with GitHub** سے اکاؤنٹ بنائیں (مفت **Hobby** پلان کافی ہے)۔
2. **Add New… ← Project** دبائیں۔
3. فہرست میں **farooq-bizmanager** ڈھونڈیں اور **Import** دبائیں۔
4. **Environment Variables** کھولیں اور ایک چیز ڈالیں:
   - نام: `CONVEX_DEPLOY_KEY`
   - قیمت: قدم 2 والی چابی
5. باقی سب ویسا ہی رہنے دیں (درست ترتیب پروجیکٹ میں پہلے سے موجود ہے) اور **Deploy** دبائیں۔
6. 2 سے 4 منٹ انتظار کریں۔ جب **Congratulations** نظر آئے تو اپنی سائٹ کی تصویر پر کلک کر کے کھولیں۔

### قدم 4 — مالک کا اکاؤنٹ بنائیں

> ⚠️ یہ **فوراً** کریں۔ نئی تنصیب پر جو شخص سب سے پہلے ویب سائٹ کھولے، وہی مالک بنتا ہے۔

1. ویب سائٹ پر **پہلی بار کی ترتیب** کا فارم آئے گا۔
2. کمپنی کا نام، اپنا نام، ای میل اور پاس ورڈ (کم از کم 8 حروف) لکھیں۔
3. **اکاؤنٹ بنائیں اور شروع کریں** دبائیں۔ اب آپ مالک ہیں اور ڈیش بورڈ پر ہیں۔

### قدم 5 — پہلے کرنے کے کام

1. **کمپنی پروفائل** — اپنا ملک چنیں۔ کرنسی، ٹیکس، تاریخ کا انداز اور مالی سال خود بھر جائیں گے۔
2. **حساب کتاب ← کھاتوں کی فہرست** — تیار کھاتے استعمال کریں یا اپنے بنائیں۔
3. **صارفین اور کردار ← ٹیم ممبر شامل کریں** — ہر شخص کو ای میل اور ابتدائی پاس ورڈ دیں۔ وہ اسی ویب سائٹ پر سائن اِن کریں گے۔
4. اپنی مصنوعات، گاہک اور سپلائر ڈالیں۔ ہر ایک پر ابتدائی بقایا اور ابتدائی اسٹاک لکھا جا سکتا ہے۔

بس۔ اپنی ویب سائٹ کا پتہ محفوظ کر لیں۔

## اختیاری: ای میل بھیجنا

اس کے بغیر بھی سب کچھ چلتا ہے — صرف خودکار ای میلیں (ادائیگی کی یاددہانی، رسید، کم اسٹاک کا انتباہ) نہیں جاتیں۔

1. **https://resend.com** پر مفت اکاؤنٹ بنائیں اور اپنا ڈومین جوڑیں (وہ طریقہ بتاتے ہیں)۔
2. ایک **API key** بنائیں۔
3. Convex کے ڈیش بورڈ میں: پروجیکٹ ← **Production ← Settings ← Environment Variables** میں ڈالیں:
   - نام: `RESEND_API_KEY`
   - قیمت: آپ کی چابی

## نئے ورژن پر اپڈیٹ

1. گٹ ہب پر اپنی نقل کھولیں۔
2. اگر نیا ورژن ہو تو **Sync fork** نظر آئے گا۔ اسے دبائیں، پھر **Update branch**۔
3. چند منٹ میں Vercel خود ویب سائٹ دوبارہ بنا دے گا۔ آپ کا ڈیٹا نہیں چھیڑا جاتا۔

## مالک کا پاس ورڈ بھول گئے

ٹیم کے ارکان: مالک **صارفین اور کردار** میں چابی کے بٹن سے نیا پاس ورڈ لگا دے۔

مالک خود:
1. Convex کا ڈیش بورڈ کھولیں ← پروجیکٹ ← **Production ← Functions**۔
2. **authActions ← resetPasswordByEmail** ڈھونڈیں اور **Run** دبائیں۔
3. یہ لکھ کر چلائیں:
   ```
   {"email": "you@example.com", "newPassword": "a-new-password"}
   ```
4. نئے پاس ورڈ سے سائن اِن کریں۔

## بیک اپ

آپ کا ڈیٹا Convex میں ہے۔ Convex ڈیش بورڈ میں بیک اپ اور ایکسپورٹ کی سہولت استعمال کریں
(**https://docs.convex.dev** پر «Backup & Restore» دیکھیں)، اور باقاعدگی سے ایک نقل رکھیں۔
ایپ کا **ڈیٹا** والا صفحہ بھی جدولیں CSV میں نکال سکتا ہے۔

---

## عوامی نمونہ چلانا

ایسا نمونہ لگانے کے لیے جسے کوئی بھی آزما سکے، طریقہ الف سے تنصیب کریں،
پھر Convex کے ڈیش بورڈ میں **Production ← Settings ← Environment Variables** میں ڈالیں:

- نام: `DEMO_MODE`
- قیمت: `true`

اور ایک بار **Functions ← demoActions ← reset** چلائیں۔ چند سیکنڈ میں فرضی کمپنی بن جاتی ہے۔ اس کے بعد:

- سائن اِن کے صفحے پر **نمونہ آزمائیں** کا بٹن آتا ہے (`demo@example.com` / `demo12345`)،
- ہر اسکرین پر «عوامی نمونہ» کی پٹی نظر آتی ہے،
- پاس ورڈ، کردار اور لوگوں کو ہٹانا بند رہتا ہے، تاکہ کوئی آنے والا دوسروں کو باہر نہ کر سکے،
- ہر رات 00:00 UTC پر سب کچھ مٹ کر دوبارہ بنتا ہے۔

**اصلی ڈیٹا والی تنصیب پر `DEMO_MODE` کبھی نہ لگائیں** — رات کی صفائی سب کچھ مٹا دیتی ہے۔

## ب۔ اپنا سرور (آئی ٹی والوں کے لیے)

Convex کا سرور خود چلائیں، اور ویب سائٹ کسی بھی ویب سرور سے دکھائیں۔

1. اپنا Convex سرور ان کی سرکاری رہنمائی سے لگائیں:
   **https://github.com/get-convex/convex-backend/tree/main/self-hosted**
   (عام طور پر Docker سے)۔ سرور کا پتہ لکھ لیں (مثلاً `http://your-server:3210`)، اور رہنمائی کے مطابق **admin key** بنائیں۔
2. ایسی مشین پر جہاں Node.js 20 یا نیا اور pnpm ہو:
   ```bash
   git clone https://github.com/FarooqStars/farooq-bizmanager.git
   cd farooq-bizmanager
   pnpm install
   ```
3. ایک فائل `.env.local` بنائیں:
   ```
   CONVEX_SELF_HOSTED_URL=http://your-server:3210
   CONVEX_SELF_HOSTED_ADMIN_KEY=<your admin key>
   VITE_CONVEX_URL=http://your-server:3210
   ```
4. سرور کا کوڈ چڑھائیں، پھر ویب سائٹ بنائیں:
   ```bash
   npx convex deploy
   pnpm build
   ```
5. `dist` فولڈر کسی بھی ویب سرور سے دکھائیں (nginx، Caddy، IIS…)۔ ہر نامعلوم راستہ `index.html` پر جانا چاہیے۔
6. ویب سائٹ کھولیں اور **پہلی بار کی ترتیب** مکمل کریں (طریقہ الف کا قدم 4)۔

ای میل کے لیے سرور پر یہ لگائیں:
```bash
npx convex env set RESEND_API_KEY <your key>
```

یہ طریقہ لینکس پر اپنے Convex سرور کے ساتھ جانچا گیا ہے۔

## ج۔ ڈویلپر طریقہ

```bash
git clone https://github.com/FarooqStars/farooq-bizmanager.git
cd farooq-bizmanager
pnpm install
npx convex dev      # ترقیاتی ڈیٹا بیس بناتا ہے اور ساتھ رکھتا ہے
pnpm dev            # دوسری ونڈو میں — سائٹ http://localhost:5173 پر
pnpm test           # 131 ٹیسٹ
```

کون سی چیز کہاں ہے:

| فولڈر | اندر کیا ہے |
|---|---|
| `convex/` | سرور: ڈیٹا بیس کی ساخت، کاروبار اور حساب کتاب کے سارے اصول |
| `convex/lib/ledger.ts` | اندراج کا انجن — ہر روزنامچہ اندراج یہیں سے گزرتا ہے |
| `convex/authActions.ts` | اندرونی سائن اِن |
| `convex/__tests__/` | ٹیسٹ |
| `src/pages/` | ہر اسکرین کا الگ فولڈر |
| `src/locales/` | انگریزی، اردو اور عربی عبارتیں |

حصہ ڈالنے والوں کے لیے اصول: پیسہ ہلانے والی ہر تبدیلی `lib/ledger.ts` سے متوازن اندراج کرے،
اندراج کے تالے (`enforcePostingDate`) کا احترام کرے، اور اس کے ساتھ ایسا ٹیسٹ ہو جو تبدیلی ہٹانے پر **فیل** ہو۔
